Learn Languages App
A web application for learning languages. It allows users to practice translating Finnish words into English and vice versa, while keeping track of their score.

Features:
    -Teacher Page: Allows adding, editing, and deleting word pairs (Finnish-English).
    -Student Page: Allows students to practice their vocabulary by entering English translations for Finnish words and getting a score based on correct answers.

Technologies Used
    -React (Frontend)
    -Node.js and Express (Backend)
    -SQlite (Database)
